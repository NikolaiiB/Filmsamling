## Start programmet
1. Kontrollér under **File → Project Structure → Project**, at JDK 27 er valgt i SDK-feltet.
2. Find main-klassen `src/main/java/main.java`. Højreklik på `main.java` og tryk **Run 'Main.main()'**.
3. Følg instruktionerne i konsollen og indtast de tal eller oplysninger programmet beder om.
